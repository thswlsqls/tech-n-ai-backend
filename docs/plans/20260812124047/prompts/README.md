## 루프가 어떻게 나아지는가

매 라운드 끝에 `_harness.md`의 **Phase 5(평가체계 자체 점검)** 를 돌린다. 아래 신호가 잡히면
그 자리에서 채점 방식을 고치고 이력을 남긴 뒤, 그 변경을 다음 라운드 프롬프트에 반영한다.

- 새 결함의 절반 이상이 직전 수정 산물 → 동결 범위를 넓힌다
- 같은 자리 3회 이상 수정 → 감점 대상에서 빼고 사람에게 올린다
- 축 점수가 2라운드 연속 하락하는데 결함 수는 그대로 → 그 축의 채점 범위를 닫는다
- 합격선 도달 조건이 산수상 불가 → 기준을 개정하고 버전을 올린다
- 위원이 잘린 출력으로 오보 → 계수 규칙을 실명으로 적는다
- 같은 이관 항목이 두 라운드 연속 재등장 → 감점 금지 목록에 명시한다

라운드 사이에 상태를 넘기는 것이 이 루프의 핵심이다. 지금까지는 위원이 매번 깨끗한 세션에서
시작해 **이미 검증된 것을 다시 의심했고**, 그래서 결함 수가 29 → 26 → 33 → 30으로 줄지 않았다.
유일하게 크게 오른 축(B, 89 → 97)이 검증 범위를 닫은 축이었다는 것이 근거다.
