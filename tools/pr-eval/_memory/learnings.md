# 누적 학습 — PR을 넘어 남는 것

`신호 / 배운 것 / 다음 라운드에 어떻게 쓰나` 세 줄로 적는다.
`runs/`는 PR마다 버려지지만 이 파일은 남는다. **PR 하나에만 해당하는 것은 여기 적지 않는다** — `runs/<…>/rounds/`에 적는다.

**아래 첫 표의 행은 처방이 아직 규칙 문서·스크립트에 들어가지 않은 것이다.** 각 스테이지 Phase 0 에서 먼저 확인하고, 규칙에 넣었으면 그 행을 맨 아래 "규칙에 이미 박은 것" 표로 옮긴다.
표에 적는 것과 규칙에 박는 것은 별개 작업이다 — 적어 두기만 한 처방은 같은 실패를 다시 부른다(L0-16 → L0-21).

## 규칙에 이미 박은 것 — 프롬프트에 싣지 않는다

처방이 규칙 문서·스크립트·설정에 이미 들어가 위 표에서 옮긴 항목이다. 세션은 이 절을 읽지 않아도 된다 — 규칙 문서를 읽으면 같은 내용을 받는다.
