## 원본 하니스에서 물려받은 것 — 다시 배우지 않는다

원본(`docs/reference/eval-harness/buzzvill-assignments/`)이 4라운드에 걸쳐 배운 것 중
장치로 이미 박아 넣은 것들이다. **여기 있는 것을 "새로 배웠다"고 다시 적지 않는다.**

| 원본이 배운 것 | 어디에 박았나 |
|---|---|
| 지적이 맞아도 처방이 새 버그를 만든다 | 반박자 질문 ⑥ (`02-judges.md` §5) |
| 취합자가 새로 쓴 코멘트의 처방에는 아무도 ⑥을 안 돌린다 | 취합자 자가 적용 (`00-criteria.md` §7) |
| 코멘트 A의 처방이 코멘트 B의 처방과 충돌한다 | PG3 (`01-stages.md` §7) |
| 요약 표가 blocking 전건을 안 담았다 | PG2 |
| 두 산출물이 서로 모순됐다 | 산출물 간 교차 대조 (`00-criteria.md` §7) |
| 검증기가 깊어지면 "전체 0건"이 도달 불가가 된다 | S3을 "이번 라운드에 손댄 자리"로 한정 (`01-stages.md` §4) |
| 이월분이 검증을 안 거쳤는데 확정 사실처럼 보인다 | 이월 항목에 `미검증` 표기 |
| 반박자가 척도에 없는 등급을 만들어냈다 | 판정 선택지 4개 고정 (`02-judges.md` §5) |
| 작성 습관 때문에 매번 다시 쓴 판이 이겼다 | 문단 쓰기 전 두 줄 선언 (`00-criteria.md` §6) |
| 점수 블록이 저자를 수정이 아니라 항변으로 이끈다 | 점수를 아예 안 쓴다 (`00-criteria.md` §3) |
