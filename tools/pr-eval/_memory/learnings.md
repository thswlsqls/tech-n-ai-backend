장치로 이미 박아 넣은 것들이다. **여기 있는 것을 "새로 배웠다"고 다시 적지 않는다.**

| 원본이 배운 것 | 어디에 박았나 |

| 코멘트 A의 처방이 코멘트 B의 처방과 충돌한다 | PG3 (`01-stages.md` §7) |
| 요약 표가 blocking 전건을 안 담았다 | PG2 |
| 두 산출물이 서로 모순됐다 | 산출물 간 교차 대조 (`00-criteria.md` §7) |
