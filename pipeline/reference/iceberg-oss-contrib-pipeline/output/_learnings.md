# Pipeline Learnings — run 간 영속 메모리 (Apache Iceberg)

이 파일은 파이프라인이 **반복할수록 똑똑해지는** 단일 메커니즘이다.
- P0(Setup)에서 오케스트레이터가 읽어 발굴/검증 에이전트에 주입한다.
- P0는 §0의 pending PR을 `gh pr view`로 자동 조회해 결과(merged/closed)를 §2 캘리브레이션으로 옮긴다(closed-loop).
- P4(Draft+Learn)에서 이번 run의 결과를 아래 섹션에 **한 줄씩 append**한다.
- 별도 통계엔진·DB·트래킹 커맨드를 만들지 않는다. 마크다운 한 장으로 충분하다.

규칙: 사실만 기록한다(추측 금지). 각 줄에 `run=yyyyMMddHHmmss` 태그를 단다.
