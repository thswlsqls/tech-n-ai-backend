- 어드민: 대상 유저를 골라 그 유저의 보유 멤버십을 보여주고, 상품을 골라 부여하거나 기존 멤버십을 삭제한다. 어드민 조회는 전용 엔드포인트가 없어 대상 유저 id를 `X-User-Id`에 실어 `GET /me/memberships`를 재사용한다. 어드민 부여/삭제는 관리자 id를 헤더로, 대상 유저 id를 경로로 보낸다. 비어드민 유저로 접근하면 안내 문구만 보인다.
- 서버 상태는 `useResource` 훅 하나로 로딩/에러/갱신을 처리한다(react-query 등 라이브러리 미도입). 유저·대상 전환 시 이전 요청 결과를 무시해 경쟁 조건을 막는다.

## 수동 확인
Rails 서버(`bin/rails db:prepare` 후 `bin/rails server`)와 `npm run dev`를 함께 띄우고 브라우저에서 확인:
1. 헤더 드롭다운으로 일반 유저(김링글) 선택 → 홈에서 상품 구매 → 보유 멤버십 카드에 나타남.
2. 드롭다운으로 관리자로 전환 → 어드민 화면에서 그 유저를 골라 방금 산 멤버십을 삭제.
3. 다시 그 유저로 전환 → 홈에서 멤버십이 사라짐.

자동 테스트는 fetch를 stub하므로 실제 백엔드 연동은 이 수동 확인으로 검증한다.
